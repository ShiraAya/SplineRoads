当前用户要求覆盖旧0440“匝道默认可埋地”和0443“外侧闭区全部不绿化”的过宽解释：
1. 外侧车道应与其他车道等驾驶宽；匝道路肩不能误算成驾驶带。图1。
2. 闭区有足够空间时生成绿化，无足够空间时省略。按实际局部容纳体积检查，不能按外侧槽位一律禁用。图2。
3. 匝道与汇入段路面、标线及护栏断面连续，避免突然错宽。图3。
4. 连接器匝道仅在路面低于地面处属于地下段。逐段可共存地面/高架/地下结构；独立于AUTO/OVER/UNDER/KEEP避障关系。
5. 地下段净空4格，地面高于路面不足5格或顶板暴露于外界时不生成顶板，只生成高出当地地面少许的两侧挡墙。高差达到5格且顶板完全埋地才封顶。图4。
6. 新增允许隧道开关，默认关闭。关闭时普通接头之间的匝道尽量保持地上，UNDER不自动授权埋地。接头本身地下时正常考虑必要地下连接，不受该开关阻断；地上和地下道路任意高低连接均可。
