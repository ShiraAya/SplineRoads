## 新操作：外侧合流缩减

在同向至少两车道的独立道路上，先于最外侧槽位布置上游手动蓝色合流点及下游手动补入目标点，再右键上游点点击“外侧合流缩减”。默认32格渐变向同向邻道合流，不建任何汇出匝道；之后用连接器选下游原槽位点并使用“补入车道空位”。提前放好目标点可避免空位无路面不能直接点击放点。

删补入后独立缩减仍存在；取消缩减后恢复原主路。已有补入引用时不能直接取消造成重叠，先删除或改汇入模式；删除合流点仍需依赖确认与所有权。自动点不可用，不能导入对向/已关闭接收车道，也不能清空该方向唯一车道。该工具入口为本轮实现选择，用户原文没有指定按钮位置。仍限同一稳定实际路段，不新增跨路段传播；保留车道分离任意槽位及整车道分离原限制不变。
