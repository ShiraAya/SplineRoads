## 一次性导入工具

本轮聊天附件将提供 `SR_GitHub_Import_Package.zip`，内含从用户原始 `SR.zip` 提取的源码、资源、测试、构建入口和许可文件，以及逐文件 SHA-256 清单和 Windows PowerShell 导入脚本。

导入脚本在用户电脑上使用正常 Git 认证。不得把 GitHub token 粘贴到聊天。导入至 `chat/sr-0402`，核查远端起点和每个文件的校验值；遇到已有不同内容时停止，不自动覆盖。推送失败会保留本地工作目录，不能把本地提交说成已经同步。

构建输出、Gradle 缓存、根运行日志和本机编辑器设置不放入源码树。原上传 ZIP 留在聊天作为原始输入；公开仓库不默认附带其中的本机缓存和日志。

## 50 分钟边界

`AGENTS.md` 规定分阶段远端提交、约 45 分钟收尾、50 分钟检查点保存后暂停。它不是系统级定时中断器，也不自动适用于没有读取该文件的其他会话。下一轮必须先读取仓库规则和进度。

不要用定时提醒代替保存工作中的文件。只有已验证远端提交或已生成并校验的附件，才算本轮可恢复成果。
