## Q2-20真实原因

LEFT借镜像坐标下RIGHT求解，回世界坐标仍为左转，旧异常却泄露RIGHT文字。现传入原请求身份，RIGHT仍右转，LEFT为定向左转。相同过紧布局原LEFT“放不进右转空间”，新LEFT“放不进定向左转空间”；两者仍拒绝空间不足。24可行镜像组合逐点位置/方向/法向对照，确认没有把右转结果改名。AUTO仍比较合法路径，显式LEFT不暗中退回RIGHT。
